미리보기에서 사진을 끌어 옮기고, 두 손가락으로 벌려 확대할 수 있습니다. 마우스는 끌기와 휠입니다. 슬라이더는 더 미세하게 맞출 때 쓰세요.

문구는 띠 끝까지 같은 간격으로 반복됩니다. 띠 높이를 0 으로 두면 글자에 딱 붙습니다. 미리보기에서 띠를 위아래로 끌어 옮길 수도 있습니다 — 슬라이더는 더 미세하게 맞출 때 쓰세요.

완성한 티켓 저장

폰에서는 공유 창이 열립니다. 거기서 이미지 저장을 고르면 사진첩에 들어갑니다. 세로 1170 × 2532로 뽑으며, 흐르는 글자는 멈춘 한 장면으로 담깁니다.

입력한 내용과 사진은 이 폰 안(브라우저 저장소)에 자동으로 저장됩니다.

백업

브라우저 데이터를 지우면 티켓도 사라집니다. 남겨 두려면 파일로 받아 두세요.

홈 화면에 올리기

아이폰 사파리는 공유 → 홈 화면에 추가, 안드로이드 크롬은 메뉴 → 앱 설치. 한 번 열어 두면 인터넷이 끊겨도 그대로 열립니다.

전체화면은 홈 화면에서 연 쪽이 낫습니다. 브라우저로 열면 위아래에 주소창·도구막대 자리가 남지만, 홈 화면에 올려 두고 열면 사진이 화면 끝까지 찹니다.

앱 버전

저장해 둔 화면이 남아 옛 모습이 보일 때 누르세요. 만든 티켓은 지워지지 않습니다.

티켓 모양을 꾸며 보는 디자인 도구입니다. 실제 입장권으로는 쓸 수 없습니다.
