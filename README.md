# 모바일 티켓 메이커

배경 사진을 넣고, 맨 아래에 글자가 계속 흘러가는 **나만의 모바일 티켓**을 만들어 보는 PWA입니다.
설치 없이 브라우저로 쓰고, 홈 화면에 올리면 앱처럼 열립니다. 인터넷이 끊겨도 동작합니다.

## 폰에서 쓰는 화면

폰을 기준으로 만들었습니다.

- **위쪽은 실시간 미리보기.** 바꾸면 그 자리에서 바뀝니다. 폰 폭 그대로 그리기 때문에
  글자 크기도 실제 크기로 보입니다
- **가운데 손잡이를 끌면** 미리보기를 크게·작게 (두 번 누르면 기본 크기로)
- **아래쪽은 탭 바** — 사진 · 글자 · 저장. 펼쳤다 접었다 할 필요가 없습니다
- **미리보기 안에서 사진을 바로 끌어** 자리를 맞춥니다. 전체화면은 손잡이 오른쪽 버튼으로 엽니다.
  전체화면일 때는 기기의 위아래 띠도 흰색이 됩니다.
  잘리는 모습은 **전체화면이 저장될 이미지와 같습니다** —
  위쪽 미리보기는 납작해서 세로로 더 잘려 보입니다
- 입력칸은 16px이라 아이폰에서 글자를 넣을 때 화면이 확대되지 않습니다

가로가 넓은 화면(데스크톱)에서는 왼쪽에 편집기, 오른쪽에 폰 모양 미리보기가 나란히 놓입니다.

## 할 수 있는 것

- **배경 사진** — 폰 앨범·카메라에서 바로 올리고, **미리보기에서 사진을 끌어 옮기고 두 손가락으로 벌려 확대**합니다
  (마우스는 끌기와 휠). 더 미세하게 맞출 때는 슬라이더를, 처음으로 돌릴 때는 *가운데로 되돌리기* 를 쓰세요.
  사진은 **올린 그대로** 나옵니다. 글자가 안 보이면 *사진 → 색감* 에서 어둡게·흐림·흑백을 올리면 됩니다
- **겹쳐 올리는 사진** — 배경 위에 사진을 한 장 더 얹습니다. **겹친 사진을 끌면** 그 사진이,
  **밖을 끌면** 배경이 움직입니다. 두 손가락으로 크기와 각도를 바꾸고, 슬라이더로 크기·위치·회전·
  투명도·둥근 모서리·그림자를 다듬습니다. 투명한 PNG는 투명한 채로 올라갑니다
- **이미지로 저장** — 완성한 티켓을 1170 × 2532 PNG로 뽑습니다. 폰에서는 공유 창이 열리고, 거기서
  *이미지 저장* 을 고르면 사진첩에 들어갑니다. 흐르는 글자는 멈춘 한 장면으로 담깁니다
- **흐르는 글자** — 문구·글꼴·크기·굵기·자간·색·띠 배경색/투명도·속도·방향(←/→)·기울임을 지정합니다.
  문구는 띠가 찰 때까지 같은 간격으로 반복됩니다.
  기본값은 검정 띠에 맑은 고딕, “캡처화면은 입장이 제한됩니다.”
- **띠 위치** — 띠를 바닥에서 띄워 사진 위 아무 높이에나 놓을 수 있습니다.
  **미리보기에서 띠를 위아래로 끌면** 되고, *글자 → 서식 → 띠 위치* 슬라이더로 0.5%씩 미세하게 맞춥니다.
  티켓 높이의 %라서 작은 미리보기·전체화면·저장한 이미지에서 자리가 똑같습니다
- **잠기는 전체화면** — 전체화면은 **잠겨 있습니다.** 스치듯 눌러도 닫히지 않고,
  화면의 **한 점을 5초 동안 꾹** 누르고 있어야 빠져나옵니다. 누르는 자리에 동그란 게이지가 차오르고,
  손가락이 움직이면 처음부터 다시 셉니다. 보는 동안 화면이 꺼지지 않습니다(지원 기기)
- **화질** — 올린 사진을 **다시 인코딩하지 않고 그대로** 담습니다(긴 변 3000px 이하, 8MB 이하).
  그보다 크면 긴 변 3000px로 줄이고, 투명한 부분이 있으면 PNG로 담아 투명도를 지킵니다
- **티켓 여러 장** — 만들고, 복제하고, 이름 바꾸고, 골라서 엽니다
- **내보내기/가져오기** — 설정을 `.json` 한 개로 주고받습니다 (사진 포함)

## 써 보기

GitHub Pages로 올린 뒤 `https://<계정>.github.io/mobile-ticket-maker/` 로 접속합니다.

- **아이폰(사파리)** — 공유 → “홈 화면에 추가”
- **안드로이드(크롬)** — 메뉴 → “앱 설치” (또는 앱 안의 *홈 화면에 앱 설치* 버튼)

## 내 PC에서 열기

서비스워커는 `file://` 에서 동작하지 않으므로 간단한 서버로 엽니다. Node 18 이상만 있으면 됩니다.

```bash
node tools/serve.mjs
```

그 다음 `http://localhost:5173` 으로 접속합니다. (포트를 바꾸려면 `node tools/serve.mjs 8080`)

## 폴더 구조

```
index.html              앱 전체 (HTML + CSS + JS 한 파일)
manifest.webmanifest    PWA 설치 정보
sw.js                   서비스워커 (오프라인 캐시)
assets/                 아이콘 PNG
tools/make-icons.mjs    아이콘을 다시 그린다 (node tools/make-icons.mjs)
tools/serve.mjs         로컬 확인용 정적 서버
```

빌드 도구도, npm 설치도, 외부 CDN도 쓰지 않습니다. `index.html` 을 열면 그게 전부입니다.

## 사진과 입력한 내용은 어디에 있나

전부 **그 기기의 브라우저 저장소(IndexedDB)** 에만 들어갑니다. 서버로 보내지 않고, 보낼 곳도 없습니다.
브라우저 데이터를 지우면 함께 사라지므로, 남겨 두고 싶으면 *저장 · 설치 → 설정 내보내기* 로 `.json` 을 받아 두세요.

## 알아 두기

티켓 모양을 꾸며 보는 **디자인 도구**입니다. 실제 입장권으로 쓸 수 있는 것이 아닙니다.
