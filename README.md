# 모바일 티켓 메이커

배경 사진을 넣고, 맨 아래에 글자가 계속 흘러가는 **나만의 모바일 티켓**을 만들어 보는 PWA입니다.
설치 없이 브라우저로 쓰고, 홈 화면에 올리면 앱처럼 열립니다. 인터넷이 끊겨도 동작합니다.

## 폰에서 쓰는 화면

폰을 기준으로 만들었습니다.

- **위쪽은 실시간 미리보기.** 글자색을 바꾸면 그 자리에서 바뀝니다. 폰 폭 그대로 그리기 때문에
  글자 크기도 실제 크기로 보입니다
- **가운데 손잡이를 끌면** 미리보기를 크게·작게 (두 번 누르면 기본 크기로)
- **아래쪽은 탭 바** — 사진 · 글자 · 정보 · 모양 · 저장. 펼쳤다 접었다 할 필요가 없습니다
- **미리보기를 누르면 전체화면.** 아래로 쓸어내리면 닫힙니다
- 입력칸은 16px이라 아이폰에서 글자를 넣을 때 화면이 확대되지 않습니다

가로가 넓은 화면(데스크톱)에서는 왼쪽에 편집기, 오른쪽에 폰 모양 미리보기가 나란히 놓입니다.

## 할 수 있는 것

- **배경 사진** — 폰 앨범·카메라에서 바로 올리고 맞춤(채우기/전체 보기), 위치, 확대, 어둡게, 흐림, 흑백 조절
- **흐르는 글자** — 문구·구분 기호·글꼴·크기·굵기·자간·색·띠 배경색/투명도·속도·방향(←/→)·기울임을 모두 지정.
  실제 모바일 티켓처럼 **현재 시각**을 함께 흘려보낼 수 있습니다.
  기본값은 검정 띠에 맑은 고딕, “캡처화면은 입장이 제한됩니다.”
- **티켓 정보** — **기본은 없음.** 배경 사진과 흐르는 글자만 있는 티켓이 기본값입니다.
  *모양 → 티켓 정보 넣기* 를 켜면 **정보** 탭이 생기고, 공연명·부제·배지·일시·장소·좌석·매수·
  예매번호·예매자·추가 항목 1개와 바코드 자리를 올릴 수 있습니다. 비워 둔 항목은 나타나지 않습니다
- **모양** — 강조색, 글자색, 제목 글꼴·크기, 정보 카드 투명도/흐림, 상단바, 바코드 영역, 글자 그림자, 홀로그램 반짝임
- **사진 넣기** — 앨범에서 고르거나 카메라로 바로 찍기. 긴 변 1600px로 줄여 저장합니다
- **미리보기** — 전체화면으로 진짜 모바일 티켓처럼. 보는 동안 화면이 꺼지지 않습니다(지원 기기)
- **티켓 여러 장** — 만들고, 복제하고, 이름 바꾸고, 골라서 엽니다
- **내보내기/가져오기** — 설정을 `.json` 한 개로 주고받습니다 (사진 포함)

## 써 보기

GitHub Pages로 올린 뒤 `https://<계정>.github.io/mobile-ticket-maker/` 로 접속합니다.

- **아이폰(사파리)** — 공유 → “홈 화면에 추가”
- **안드로이드(크롬)** — 메뉴 → “앱 설치” (또는 앱 안의 *홈 화면에 앱 설치* 버튼)

## 내 PC에서 열기

서비스워커는 `file://` 에서 동작하지 않으므로 간단한 서버로 엽니다. Node 18 이상만 있으면 됩니다.

```bash
node tools/serve.mjs
```

그 다음 `http://localhost:5173` 으로 접속합니다. (포트를 바꾸려면 `node tools/serve.mjs 8080`)

## 폴더 구조

```
index.html              앱 전체 (HTML + CSS + JS 한 파일)
manifest.webmanifest    PWA 설치 정보
sw.js                   서비스워커 (오프라인 캐시)
assets/                 아이콘 PNG
tools/make-icons.mjs    아이콘을 다시 그린다 (node tools/make-icons.mjs)
tools/serve.mjs         로컬 확인용 정적 서버
```

빌드 도구도, npm 설치도, 외부 CDN도 쓰지 않습니다. `index.html` 을 열면 그게 전부입니다.

## 사진과 입력한 내용은 어디에 있나

전부 **그 기기의 브라우저 저장소(IndexedDB)** 에만 들어갑니다. 서버로 보내지 않고, 보낼 곳도 없습니다.
브라우저 데이터를 지우면 함께 사라지므로, 남겨 두고 싶으면 *저장 · 설치 → 설정 내보내기* 로 `.json` 을 받아 두세요.

## 알아 두기

티켓 모양을 꾸며 보는 **디자인 도구**입니다. 바코드 자리는 예매번호로 만든 장식 무늬이고,
실제 입장권으로 쓸 수 있는 코드가 아닙니다.
